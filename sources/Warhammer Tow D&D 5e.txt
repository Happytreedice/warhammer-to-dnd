Готово. Собрал новую ревизию **без генерации изображений/токенов**, с раздельными compendium packs по фракциям и группировкой через `packFolders`.

[Скачать финальный ZIP](sandbox:/mnt/data/warhammer-tow-dnd5e-v14-packfolders-icons-no-tokens.zip)

Что изменено в этой ревизии:

- **Отдельные packs по фракциям** сохранены:
  - `*-actors`
  - `*-items`
  - `old-world-spells`
  - `shared-traits-and-features`
  - `conversion-journals`
- Все packs сгруппированы в `module.json` через:
  - `packFolders → Warhammer Conversions`
- Полностью убрана генерация кастомных изображений:
  - нет `assets/tokens/`
  - все Actor используют стандартный core Foundry path `icons/svg/mystery-man.svg`
  - Items / Spells / Features / Equipment используют стандартные `icons/...`
- В каждый Actor добавлены явные варианты вооружения как отдельные embedded `Item` в inventory.
- Всего добавлено **1361 embedded weapon option**.
- Сохраняется unpacked source формат:
  - `src/packs/<pack-name>/*.json`
- Packs скомпилированы через `@foundryvtt/foundryvtt-cli` / `fvtt package pack`, который читает сериализованные JSON-документы и пишет compendium database в `packs/`. ([github.com](https://github.com/foundryvtt/foundryvtt-cli?utm_source=chatgpt.com))
- `module.json` содержит `packs` и `packFolders`; этот подход соответствует manifest-структуре compendium packs / packFolders. ([foundryvtt.wiki](https://foundryvtt.wiki/en/development/api/CompendiumCollection?utm_source=chatgpt.com))
- PF2e creature-building benchmark logic применён как числовая база для AC/HP/DC и затем переведён в ограниченные значения D&D 5e 2014; исходная PF2e методика использует creature-building таблицы для AC, HP, атак, DC и ролей существ. ([2e.aonprd.com](https://2e.aonprd.com/Rules.aspx?ID=995&utm_source=chatgpt.com))
